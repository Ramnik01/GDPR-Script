Privacy that doesn't nag.

GDPR-Script 2.0 is a <8 kB, dependency-free consent banner that blocks non-essential cookies before consent and respects Global Privacy Control. Equal Accept / Reject, granular categories, revocable in one click, accessible and CSP-safe.

🔒 Prior consent

All marketing / statistics scripts stay blocked until the user opts in. No cookie wall.

⚖️ Equal choice

Accept all, Reject non-essential, or Customize — same size, same contrast. No dark patterns.

♿ Accessible

Dialog role, focus trap, ESC, keyboard, prefers-reduced-motion and 4.5:1 contrast.

🛡️ Secure by default

SameSite=Lax, Secure cookies, no innerHTML with user data, no eval.

Install — 30 seconds

<link rel="stylesheet" href="gdpr.css">
<script src="gdpr.js"></script>
<script>
  GDPR.init({
    name: 'Acme',
    policyUrl: '/privacy',
    position: 'bottom', // top | bottom | center
    expiryDays: 182,
    categories: [
      { id: 'necessary', name: 'Necessary', required: true, description: '...' },
      { id: 'statistics', name: 'Statistics', description: '...' }
    ]
  })
</script>

<!-- Block until consent: -->
<script type="text/plain" data-gdpr-category="statistics"
        data-src="https://www.googletagmanager.com/gtag/js?id=G-XXXX"></script>

<iframe type="text/plain" data-gdpr-category="marketing"
        data-src="https://www.youtube.com/embed/dQw4w9WgXcQ"></iframe>

Test blocking: the analytics snippet below will only load if you Accept statistics/marketing. Open DevTools → Network and watch gtag/js stay blocked until consent.

JS API

GDPR.hasConsent('marketing') // → boolean
GDPR.getConsent()           // → { version, timestamp, categories, expiryDays } | null
GDPR.on('consent', (record) => console.log('changed', record))
GDPR.showSettings()         // open preferences modal
GDPR.resetConsent()         // clear and re-show banner (useful for testing)
GDPR.acceptAll() / GDPR.rejectAll()
